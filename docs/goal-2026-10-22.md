## 5.4 过程不一样的地方（诚实报告，不拆帘子）

以下事项**本轮没有做完**，原因如下，不应被读成「已完成」：

1. **S1/S2 仍是「尚未到判」（返回码 3）。** S1 现在只差一点：`git status` 有未提交改动（提交后就能点亮）；S2(b) 的证据文件从未生成（`s2b-verify.sh --judge`）。这两个是**证据缺失**，不是功能缺陷。
2. **S6 长期观测未满 7 天（还差 4.87 天）**，且窗口里有 2 条非 cron 整点采样。这一项本轮不属于目标（用户已明确不纳入）。
3. **shell.run 的 uid 降权是降级状态（`degraded: true`）。** 运行时 `id` 给出 `uid=1000(dot)`，而设计要求 shell 子进程是 uid 1001。根因：容器 pid1 以 uid 1000 运行 → `CapEff=0`（非 root 进程拿不到有效能力），而降权需要 `CAP_SETUID` 在 **effective** 集里。**这不是本轮引入的**：换基座前后镜像的 `Config.User` 都是 `dot`（`docker inspect fb98ec90ef9e` → `USER=dot`；换基座前的 Dockerfile 也是 `USER dot`），而降权能力来自 `buildSpec` 的 `CapAdd`（与镜像无关）。它是现有的「开放问题 Q7」，要真解需要运行时以 root 启动再降权，或在镜像里放一个带 setuid bit 的小助手（如 setpriv）——这是设计决策，不是本轮能顺手改的。
4. **`pushApprovalCards` 目前没有生产调用者**（channels 提出，我做了决定）：广播循环已经在 `feishu-outbound.ts` 的 `claimAndSend` 里（发送/审计/去重必须同处），`pushApprovalCards` 是**第二份实现**。两份实现会分叉（可能一边改了另一边没改）——而这正好是本项目发生过的「函数对但没人调」。它应当被**删掉**（或让 `claimAndSend` 去调它，收敛成一份），而不是当作可能启用的功能待着。待办：channels 或 lead 下一轮收口。
5. **事件主动打扰还没有配置入口**（`event_push_policy` 只有表，主人今天还得手插 SQL）。这是产品缺口，不是本轮的功能缺陷。
6. **消息循环里每 6 小时的保护只是兜底**（probe 实测 8 次均快于上限，hb 里 `skip probe-running` 从未触发）。

## 5.6 本轮新增的缺陷（交接表里没有的，自己算出来的）

1. **F9 镜像漂移**（P0）——容器跑的镜像与期望不一致时，旧代码会直接 adopted（只记一句「容器已就绪」）。现在先判实际镜像标识，不一致就重建。
2. **F4 回收时的退路保护**（P0）——原实现只看 tag/digest 是不是当前值，于是新镜像构建成功的第一行代码就把唯一可回滚的镜像删了。现在删之前先问「有没有容器在用」，判断不了就保守地一个不删。
3. **F2/F3 名字与真相脱节**（P1）——`pwVersion` 是个名字陈旧的字段（实际是基座标签）；`rebuild-image.sh` 写死 tag 且第一步就 `docker rmi -f` 把唯一退路删了。现在名字是 `baseImageTag`（迁移 180 重命名列），脚本现算 tag + 先打 rollback tag。
4. **重启即拒启的迁移校验**（P1）——`expectedVersion` 与迁移目录不一致时 daemon 直接拒启（今天 185）。
5. **三个 Windows 测试平台不可跑**（P1）——`file://` 解析、POSIX 假 CLI、裸 `rmSync`。修完 Windows `npm test` 从 19 个红变 0。
6. **`verify-goal.sh` 的 fork bomb**（P1）——一个多余的引号让消息里的示例命令变成了命令替换 → 脚本递归调用自己。
7. **`exec-container-concurrency` 的死锁**（P1）——不是慢，是死锁；修后它进入主全量回归，**排除列表可以删了**。
8. **两个裸保真的版本钉**（P2）——`progress-criteria.sh` 钉定 `expectedVersion: 170`；`wsl-fleet-boot.mts` 钉定 `50`（README:350 记的生产路径验证入口，自迁移 60 起就一直起不来，实测 `MigrationError: 迁移后 user_version=185，期望 50`）。
