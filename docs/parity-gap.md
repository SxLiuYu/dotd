# dotd vs OpenAI Bot 能力对标

> 2026-10-18。目标：让 dotd 在**功能和效果**上对标 OpenAI 的 bot 产品（ChatGPT Agent / GPTs / Assistants）。

## 一、能力矩阵

| 能力 | OpenAI bot | dotd 现状 | 差距 |
|---|---|---|---|
| **多轮对话、上下文记忆** | ✅ 自动 | ✅ 会话复用（第十轮修） | 无 |
| **跨会话长期记忆** | ✅ 自动提取 + 可查看/编辑 | ✅ `MEMORY.md` + `notes/` 文件化 | 无（dotd 更透明） |
| **联网搜索** | ✅ 内置搜索 + 爬取 | ⚠️ 只有 `net.get`，**没有搜索引擎** | **有** |
| **代码执行** | ✅ 沙箱 Python/Node | ✅ 真容器 `shell.run` | 无 |
| **文件读写** | ✅ 上传/下载/生成 | ✅ `fs.*`（home 卷） | 无 |
| **浏览器操作** | ✅ 真实浏览器 + 登录态 | ⚠️ `browser.*` 存在但**缺 identity 一律拒** | **有** |
| **图片生成/理解** | ✅ DALL·E / 视觉 | ❌ 无 | **有**（可能不需要） |
| **语音** | ✅ TTS/STT | ❌ 无 | **有**（可能不需要） |
| **定时任务** | ✅ 计划任务/提醒 | ⚠️ 有 heartbeat，但**没有"每天 9 点提醒我"** | **有** |
| **主动推送** | ✅ 完成任务通知 | ✅ 飞书出站 | 无 |
| **工具审批** | ✅ 危险操作确认 | ✅ 治理审批（比 OpenAI 更细） | 无（dotd 更强） |
| **多模态输入** | ✅ 图片/PDF | ❌ 只有文本 | **有** |
| **Rich 输出** | ✅ 表格/卡片/图表 | ⚠️ 纯文本 | **有** |

## 二、优先级建议（按"效果差距 / 实现成本"）

### P0：直接影响"能不能用"

1. **浏览器登录身份** —— 现在 `browser.*` 完全不可用。
   需要定义"identity 从哪来"：cookie 导入？用户手动登录一次后持久化？
2. **联网搜索** —— `net.get` 只能访问已知 URL，不能"帮我查一下最新的 XX"。
   需要接一个搜索 API（或让模型用 `net.get` 打某个搜索端点）。

### P1：明显提升体验

3. **定时任务** —— "每天 9 点提醒我看日报" 是 bot 的高频用法。
   现在只有 heartbeat，没有用户可创建的定时任务。
4. **多模态输入** —— 飞书发张图片让它看，现在读不了。

### P2：锦上添花

5. Rich 输出（表格/卡片）
6. 图片生成
