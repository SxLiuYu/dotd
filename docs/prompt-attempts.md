# 提示词路线结论：3 次全败，按纪律转代码

## 代码约束尝试 1（第 94 轮）：TOOL-REUSE-GUARD 软提醒
- **改动**：模型调 shell.run 且上下文有工具清单时，**拦一次**并回喂"你有现成工具，先看看"
- **验证**：同类任务看是否改用 tool.invoke
- **结果**：❌ 部分失败。守卫确实拦住了（`shell.run skipped`），但模型**重发一次 shell.run** 就放行了
  - 设计如此（只提醒一次、不强拦，避免"该用 shell 的活卡死"）
  - 但这说明**提醒式约束对模型无效**

## 下一步（强约束，有风险）
- **方案**：同类任务**硬拦** shell.run（拒绝执行，而不是提醒）
- **风险**：判断"同类"要精确，否则"确实该用 shell 的活"会被卡死
- **判据**：如果硬拦也不奏效，或误伤正常任务 → 回滚，S2(b) 判定为"当前模型能力不足"，记入限制说明
