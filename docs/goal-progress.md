- **关键根因与解法**（前一会话定位、本会话落地）：
  提示词试满 3 次全败；根因不是模型不听话，而是"自造工具只是注入文本里的数据"，

  不再"只要出现 tool.invoke 就算过"（那会漏掉"先 shell.run 手写一遍、失败才想到
  现成工具"和"invoke 完又用 shell.run 复核"），改要求**四条同时成立**：
  ① 有 tool.invoke；② **全程零 shell.run**；③ 工具数不变（没新建）；④ 任务 done 且有回答。

  `edit_file` 13s / 3 次调用。

      `/tmp/dotd-wsl.log **(deleted)**` —— 文件被删但 fd 仍指着它，日志全进黑洞、
      磁盘空间也不释放。三处无条件执行造成：`dotd-boot.sh` 与 `dotd-daemon-start.sh`

      "上一次怎么死的"被抹掉）。已删掉前两处 rm，第三处改为归档成 `.prev` 再新建。
      重启后 fd 指向真文件、日志正常写入。
    - **逐条反向验证 report 的每条判据，又抓到 4 处"判据在说谎"**（合成数据强制失败，
      而不是只看它打印了什么）：
      1. **成功率没进退出码**（最严重）：`process.exit` 只算了
         days/coveredDays/growth/fdGrowth/unattended/contRate，唯独漏了 `passRate`。
         于是"判定"打印 `❌ 成功率 50%` 而 **exit 仍是 0** —— "成功率不掉"是四条
         判据里最容易被长期运行磨掉的一条，却是唯一没有约束力的，等于没判。
      2. **报告不知道自己过期**（最危险）：连续性只量"样本首尾之间"，不看末尾之后。
         采样跑满 7.05 天后彻底死掉、隔 23 天再看，仍打印 `✅ 已满 7 天且观测连续`
         且 exit 0，而此刻没有任何东西在观测。数据每条都真，结论却已失效，
         而且**越晚看越像成功**。已加"末样本距今 >90 分钟即判观测已停止"。

         `❌ 观测不连续：最长空档 24.00h（容忍 1.5h）`。

    （`lstart=Mon Oct 19 20:52:34 2026`）。前几轮改代码/重启都属人工干预，样本已清空。
  - **第 5 轮：两条与"飞书/重启"直接相关的新判据缺口**：
    - **探测从不检查是否真的发到飞书了**：probe 原来只核对库里的回答内容 ——
      飞书 token 过期、权限被收回、app 被停用时，任务照样 done、答案照样对，
      而用户**一个字都收不到**，probe 依然报 ok=1。而"在飞书里干活"正是这个项目的
      目标原话。已补：答对之后再查 `surf_outbound_log` 里该 taskId 的投递记录，
      ok 必须为 1（出站写入在任务 done 后约 0.6s，最多等 10 秒再判）。
      三态验证：有 ok=1 → 通过；有 ok=0 → 失败；无记录 → 失败。实测输出多一列
      `飞书出站=1`，真实投递 id=457 ok=1。
    - **重启可以把内存泄漏"洗白"（最难发现的一条）**：RSS 判据只比较"当前生命周期"
      的首末中位数（跨重启相减确实没意义），于是每小时漏 12MB、每 2 小时自愈重启
      一次时，每段最多只涨 24MB —— 判据看到 +18MB 就判 ✅。
      合成数据实测：8 天 96 次重启、若不重启会漏 2GB，报告全绿 exit 0。
      而 S5 验收过的系统恰恰会频繁自愈，这个组合会让 S6 永远绿。
      已补：取各生命周期内 RSS 爬升速率的中位数，≥2MB/h 即失败
      （168h × 2MB/h ≈ 336MB，远超 50MB，阈值不宽松）。
      用中位数而非最大值，是因为新起的 node 进程本来就会先爬后平（预热），
      用最大值会把正常重启判成泄漏。
      **过程中还修了一个让新判据"看运气"的 bug**：分段过滤误用了 `S`
      （当前生命周期子集），96 次重启只算出 1 段、中位数实际只取了 1 个样本。
    - 验证 6 场景全对：全段漏+每2h重启 → 1；漏+每6h重启 → 1；
      只有前1/4在漏（预热）→ 0；完全平稳+96次重启 → 0；完全平稳8天 → 0；
      31次自愈重启但每段平稳 → 0。
