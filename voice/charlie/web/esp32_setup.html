⌚ ESP32 配置向导

第一步用 USB 烧录干净固件；第二步手机连设备热点配网。整套流程约 3 分钟。

① 烧录固件

烧录的固件已擦除所有 WiFi 与服务器信息，不含任何个人凭证。
烧录完成后请勿拔掉 USB，继续第二步用手机配网。
Windows 若检测不到串口，请安装 CP210x/CH340 驱动。

② 手机配网

✅ 固件烧录完成！请按以下步骤在手机上配置：

📱 配置步骤

  1. 保持设备通电，用手机打开 WiFi 设置，连接名为
    lc-s3-wifi-1.54tft-XXXX 的热点（无密码）。
  2. 连上后手机通常自动弹出配置页；如未弹出，打开浏览器访问
    http://192.168.4.1
  3. 在页面上选择你家的 WiFi 并输入密码。
  4. 点 “高级设置 / Advanced”，在 OTA URL 栏填入下方地址后保存：
加载中...
  1. 保存后设备重启，自动连接 WiFi 并接入 Charlie。设备屏幕显示时间即成功。
⚠️ 未能自动获取本机局域网 IP。请确认电脑已连 WiFi/路由器，在 Charlie 设置中查看本机 IP， 然后用 http://<电脑IP>:<端口>/xiaozhi/ota 作为 OTA 地址。

OTA 地址告诉设备去哪里获取 Charlie 的 WebSocket 连接信息。设备配网后会自动调用该地址， 无需手动填写 WebSocket 地址。请确保手机配网时，电脑和 ESP32 连在同一路由器下。
