快速开始

1. 安装

git clone https://github.com/your-repo/baize-nodejs.git
cd baize-nodejs
npm install

2. 配置

cp .env.example .env
# 编辑 .env，填入 API Key

3. 运行

npm run build
npm start

启动 API 服务

# 启动 REST API 服务（端口 3000）
node dist/interaction/api.js

# 测试
curl http://localhost:3000/health
